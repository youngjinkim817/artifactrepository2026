이름·이메일 명단(CSV)을 업로드하면 레포지토리 페이지가 생성됩니다.

명단은 버킷의 roster.json으로 저장됩니다. 아래에서 수강생을 한 명씩 직접 입력해 추가한 뒤, 명단 저장을 누르세요. 저장하면 수강생이 바로 접속할 수 있습니다.

AWS Access Code (선택 — 비워두면 나중에 아래 목록에서 입력)

2. 입력된 명단
